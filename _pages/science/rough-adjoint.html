We consider a pendulum driven by a sample path of fractional Brownian motion (fBm), which is a rough path for \(H < \tfrac12\). From noisy observations of its trajectory, we recover the unknown initial state by gradient descent, where the gradient is computed by an adjoint sweep. The same observations and driving path are used for two forward/adjoint pairings.

  • Symplectic: RSPRK, implicit midpoint forward with its symplectic partner backward
  • Not symplectic: Heun forward, Heun on the continuous adjoint backward
  • true trajectory (dashed) and true \(x_0\) (cross)
  • observations

The model

The forward system is a rough Hamiltonian system with \(H_0 = \tfrac12 p^2 - \cos q\) and \(H_1 = -\sigma\cos q\), namely

$$ \mathrm{d}q = p\,\mathrm{d}t, \qquad \mathrm{d}p = -\sin q\,\big(\mathrm{d}t + \sigma\,\mathrm{d}\mathbf{Z}_t\big), $$

driven by the geometric rough path \(\mathbf{Z}\) above \(Z\). Since there is a single rough driver alongside \(t\), the lift requires no additional Lévy area. For the loss \(J(x_0) = \tfrac12\sum_k |x(t_k) - y_k|^2\), the adjoint variable \(\lambda\) satisfies the rough adjoint system \(\mathrm{d}\lambda = -Df_0(x)^{\!\top}\lambda\,\mathrm{d}t - Df_1(x)^{\!\top}\lambda\,\mathrm{d}\mathbf{Z}_t\), with jumps \(x(t_k) - y_k\) at the observation times, and the gradient is given by \(\nabla J = \lambda(0)\). The forward and adjoint systems together form a rough Hamiltonian system, which follows from a Type-II rough variational principle with split boundary conditions. Consequently, one has the pathwise quasi-conservation law

$$ \langle \lambda(t), \delta x(t)\rangle - \sum_{t_k \ge t} \langle x(t_k) - y_k,\, \delta x(t_k)\rangle = \text{const}, $$

for every solution \(\delta x\) of the variational equation. This identity underpins adjoint sensitivity analysis.

What the plots show

Reading the plots. The top row shows the misfit \(J\) and the true gradient \(|\nabla J|\) at the current estimate after each descent step. The bottom row shows the distance between each adjoint gradient \(\lambda_0\) and a finite-difference gradient, and the quasi-conservation residual \(|Q_n|\) along the current trajectory, relative to \(\sum_k|\langle r_k,\delta x_k\rangle|\). The number at the right edge of each curve is its latest value.

RSPRK. The one-stage Gauss rough symplectic partitioned Runge–Kutta (RSPRK) method uses the implicit midpoint rule forward, \(x_{n+1} = x_n + f_0(\bar x)\Delta t + f_1(\bar x)\Delta Z_n\), together with its symplectic partner backward, \((I - \tfrac12A_n^{\!\top})\lambda_n = (I + \tfrac12A_n^{\!\top})\lambda_{n+1}\) with \(A_n = Df_0(\bar x)\Delta t + Df_1(\bar x)\Delta Z_n\). This pairing preserves the discrete quasi-conservation law to machine precision (bottom right). Consequently, the adjoint gradient is exactly the gradient of the discrete loss: its difference from a finite-difference gradient sits at the finite-difference floor (bottom left), and gradient descent drives the true gradient to zero (top right).

Heun / Heun. The forward map uses an explicit Stratonovich-consistent scheme, and the continuous adjoint equation is integrated backward with the same scheme. This pairing is not symplectic. Hence, the quasi-conservation law fails and the computed gradient is biased, increasingly so for rougher paths (smaller \(H\)) and coarser grids. Gradient descent therefore settles where the biased gradient vanishes, and the true gradient of its own loss stalls away from zero (top right).

Optimisation set-up. Gradient descent uses an Armijo backtracking line search on each scheme's own loss, along that scheme's adjoint gradient. We remark that the two losses belong to two different discrete problems, so their values are not directly comparable; what matters is whether each run reaches a stationary point of its own problem. The observations are generated from a reference solution on a 20× finer grid, perturbed by Gaussian noise of standard deviation 0.05. Changing \(H\), \(\sigma\) or the grid generates a new problem.
