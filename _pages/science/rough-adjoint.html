A pendulum is driven by a sample path of fractional Brownian motion, a rough path when \(H < \tfrac12\). From noisy observations of its trajectory we recover the unknown initial state by gradient descent, with the gradient computed by an adjoint sweep. The same observations and driving path are used with two forward/adjoint pairings.

  • Symplectic: RSPRK, implicit midpoint forward with its symplectic partner backward
  • Not symplectic: Heun forward, Heun on the continuous adjoint backward
  • true trajectory (dashed) and true \(x_0\) (cross)
  • observations

The model

The forward system is a rough Hamiltonian system with \(H_0 = \tfrac12 p^2 - \cos q\) and \(H_1 = -\sigma\cos q\):

$$ \mathrm{d}q = p\,\mathrm{d}t, \qquad \mathrm{d}p = -\sin q\,\big(\mathrm{d}t + \sigma\,\mathrm{d}\mathbf{Z}_t\big), $$

driven by the geometric rough path \(\mathbf{Z}\) above \(Z\). With a single rough driver alongside \(t\), the lift needs no extra Lévy area. For a loss \(J(x_0) = \tfrac12\sum_k |x(t_k) - y_k|^2\), the adjoint variable \(\lambda\) solves the rough adjoint system \(\mathrm{d}\lambda = -Df_0(x)^{\!\top}\lambda\,\mathrm{d}t - Df_1(x)^{\!\top}\lambda\,\mathrm{d}\mathbf{Z}_t\), with jumps \(x(t_k) - y_k\) at the observation times. Then \(\nabla J = \lambda(0)\). The adjoint and forward systems together form a rough Hamiltonian system, derived from a Type-II rough variational principle. It has the pathwise quasi-conservation law

$$ \langle \lambda(t), \delta x(t)\rangle - \sum_{t_k \ge t} \langle x(t_k) - y_k,\, \delta x(t_k)\rangle = \text{const}, $$

for every solution \(\delta x\) of the variational equation. This identity underlies adjoint sensitivity analysis.

What the plots show

Top row: the misfit \(J\) and the true gradient \(|\nabla J|\) at the current estimate, after each descent step. Bottom row: how far each adjoint gradient \(\lambda_0\) is from a finite-difference gradient, and the quasi-conservation residual \(|Q_n|\) along the current trajectory, relative to \(\sum_k|\langle r_k,\delta x_k\rangle|\). The number at the right edge of each curve is its latest value.

  • RSPRK. The one-stage Gauss rough symplectic partitioned Runge–Kutta method uses implicit midpoint forward, \(x_{n+1} = x_n + f_0(\bar x)\Delta t + f_1(\bar x)\Delta Z_n\), and its symplectic partner backward, \((I - \tfrac12A_n^{\!\top})\lambda_n = (I + \tfrac12A_n^{\!\top})\lambda_{n+1}\) with \(A_n = Df_0(\bar x)\Delta t + Df_1(\bar x)\Delta Z_n\). This preserves the discrete quasi-conservation law to machine precision (bottom right). The adjoint gradient is therefore exactly the gradient of the discrete loss: its difference from a finite-difference gradient sits at the finite-difference floor (bottom left), and gradient descent drives the true gradient to zero.
  • Heun / Heun. The forward map uses an explicit Stratonovich-consistent scheme, and the continuous adjoint equation is integrated backward with the same scheme. This pairing is not symplectic. The quasi-conservation law fails, and the computed gradient is biased, more so for rougher paths (small \(H\)) and coarser grids. Gradient descent then settles where the biased gradient vanishes, so the true gradient of its own loss stalls away from zero (top right).

Gradient descent uses an Armijo backtracking line search on each scheme's own loss, along that scheme's adjoint gradient. The two losses belong to two different discrete problems, so their values are not directly comparable. What matters is whether each run reaches a stationary point of its own problem. The observations come from a reference solution on a 20× finer grid, with Gaussian noise of standard deviation 0.05. Changing \(H\), \(\sigma\) or the grid draws a new problem.

Paper: R. Hu and M. Leok, Rough variational principles and applications to adjoint systems, preprint, 2026.
